# Летопись Героев — платформа-компаньон для D&D 2024 (SRD 5.2)

Локальное браузерное приложение для домашних игр: листы персонажей с автоматикой,
броски кубов, экран мастера (бой, бестиарий, проверки, генератор лута) и журнал кампании.
Всё на русском, все данные — в localStorage браузера, работает офлайн одним файлом.

## Как пользоваться (для игроков)

Открыть `D:\Users\Learning\D&D\DnD-Платформа.html` двойным кликом (Chrome или Edge).
Данные сохраняются автоматически в этом браузере на этом компьютере.
Кнопка «Сохранить копию» внизу слева скачивает резервный JSON; «Загрузить копию» восстанавливает.

Важно: открывать всегда один и тот же файл одним и тем же браузером — localStorage
привязан к нему. Firefox для file:// хранит данные иначе — используйте Chrome/Edge.

## Разработка

```bash
npm install
npm run dev        # дев-сервер
npm run typecheck  # только типы
npm run build      # tsc + vite → dist/index.html (один файл со всем внутри)
```

Из-за `&` в пути `D&D` не работает `npx` (ломается cmd-шим). Обходные пути:

```powershell
node .\node_modules\typescript\bin\tsc --noEmit
node .\node_modules\vite\bin\vite.js build
```

После сборки скопировать `dist/index.html` в `..\DnD-Платформа.html`.

## Стек

- Vite 6 + `vite-plugin-singlefile` — сборка в один самодостаточный HTML (~1.4 МБ)
- React 19 + TypeScript (strict)
- Zustand 5 + persist (ключ `dnd-platform-v1`, версия схемы 1)
- Кастомный CSS (без фреймворков), шрифты Cormorant/Alegreya/Marck Script
  заинлайнены как base64 (кириллица + латиница)
- Звуки синтезируются WebAudio, вся графика — inline SVG и emoji

## Архитектура

- `src/model/types.ts` — все типы данных
- `src/data/` — правила D&D 2024 на русском: 12 классов (1–20 уровни, по 2 подкласса),
  44 расы (10 PHB 2024 + популярные из других книг), 16 предысторий PHB 2024,
  ~50 черт, 179 заклинаний, 151 предмет, 54 монстра
- `src/engine/` — движок правил: `derive.ts` (производные статы: КБ, атаки, ячейки…),
  `levelup.ts`, `rest.ts`, `loot.ts`, `dice.ts`, `rolling.ts` (бросок+журнал+оверлей)
- `src/store/store.ts` — единый Zustand-store (персонажи, журнал, бой, броски, настройки)
- `src/features/` — экраны: home, characters (лист, мастер создания, level-up),
  dice, master (бой/бестиарий/проверки/лут), journal, library
- `src/components/` — Modal, Toasts, RollOverlay, Confetti, Embers, Sidebar

Правило хитов: храним броски кости за каждый уровень (`hpRolls`), максимум хитов
всегда выводится движком — рост Телосложения и черты пересчитываются задним числом,
как по правилам 2024.
